# 슬래시 커맨드 튜토리얼 기여 가이드

## 적용 범위 및 프로젝트 구조

이 지침은 `slash-command/` 폴더에 적용하며, 저장소 루트의 `AGENTS.md`와 함께 따릅니다. HTML, CSS, 순수 JavaScript로 구성된 독립적인 한국어 학습 페이지입니다.

- `index.html`: 페이지 구조, 검색·필터 UI, 공식 문서 링크를 관리합니다.
- `styles.css`: 색상, 카드, 키보드 포커스, 반응형 레이아웃을 정의합니다.
- `app.js`: 명령 데이터, 단계별 렌더링, 검색, 환경 필터, 복사 기능을 구현합니다.
- `prompt.md`: 원래 요구사항입니다. 작업 범위를 확인할 때 참고하세요.
- `README.md`: 실행 방법, 문서 확인 날짜, 검증 결과를 기록합니다.

## 실행 및 기본 검사

빌드나 패키지 설치 없이 `index.html`을 브라우저에서 열 수 있습니다. 로컬 서버가 필요하면 저장소 루트에서 실행하세요.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/slash-command/`에 접속하세요. 기본 검사는 저장소 루트에서 실행합니다.

```sh
node --check slash-command/app.js
git diff --check
```

문법 검사만으로 화면이나 클립보드 동작이 검증되지는 않습니다. 현재 전용 테스트 프레임워크, 커버리지 기준, 린터는 없습니다.

## 구현 및 콘텐츠 작성 규칙

새 코드는 공백 두 칸으로 들여쓰고, 기존의 압축된 CSS를 작업과 무관하게 전체 재정렬하지 마세요. JavaScript 식별자는 camelCase, CSS 클래스와 HTML ID는 kebab-case를 사용하세요. 재할당이 없으면 `const`를 사용합니다.

명령 목록은 `app.js`의 `commands`, 학습 단계는 `steps`, 환경 표시는 `environments`에서 관리하세요. 명령을 추가하거나 삭제하면 화면 소개 문구와 README의 개수도 함께 맞추세요. 초보자가 자주 사용할 명령을 학습 순서대로 배치하고, 한국어 설명을 간결하게 유지하세요.

지원 환경과 동작을 수정할 때는 공식 OpenAI 문서를 확인하세요. 동일 기능이 다른 UI에 있다는 이유로 슬래시 명령 지원을 추정하지 마세요. 출처 링크와 확인 날짜도 갱신하세요.

## 동작 및 접근성 검증

- 전체·앱·IDE 확장·터미널 필터와 검색을 함께 확인하세요.
- 대소문자, 앞뒤 공백, 검색 결과 없음, 초기화를 점검하세요.
- 복사 성공·실패 안내와 `/` 검색 포커스 단축키를 확인하세요.
- 학습 순서 링크, 키보드 탐색, 포커스 표시, 상태 안내를 유지하세요.
- 데스크톱과 모바일에서 가로 넘침을 확인하고, 600px·850px 분기 전후도 점검하세요.
- 외부 글꼴 로딩 실패 시 시스템 글꼴로 읽을 수 있는지 확인하세요.
