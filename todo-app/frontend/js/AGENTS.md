# JavaScript 지침

- 식별자는 camelCase로 작성하고, 기본적으로 `const`, 재할당이 필요할 때만 `let`을 사용하세요.
- DOM이 준비된 뒤 요소를 참조하고, 이벤트는 `addEventListener`로 등록하며 중복 등록을 피하세요.
- 사용자 입력과 API 응답의 텍스트는 `textContent` 등으로 출력하고, 검증되지 않은 값을 `innerHTML`에 넣지 마세요.
- API 요청은 네트워크 실패와 HTTP 오류를 처리하고, 사용자가 이해할 수 있는 오류 안내를 제공하세요.
- 변경한 기능의 정상 동작, 빈 입력과 잘못된 입력, API 연동이 있다면 요청 실패 상황을 확인하세요.
