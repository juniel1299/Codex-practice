# 오늘의 할 일

순수 HTML, CSS, JavaScript로 만든 한국어 할 일 앱입니다. 데이터는 현재 브라우저의 localStorage에 저장되며 서버나 다른 기기와 동기화되지 않습니다.

## 실행

저장소의 이 폴더에서 다음 명령을 실행한 뒤 <http://127.0.0.1:8000/frontend/>를 여세요.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`frontend/index.html`을 직접 열어도 사용할 수 있지만, 안정적인 브라우저 저장을 위해 로컬 서버 사용을 권장합니다.

## 기능

- 할 일 추가, 완료 상태 변경, 개별 삭제
- 전체·진행 중·완료 필터와 남은 일 개수
- 완료한 일 일괄 삭제
- 자동 저장과 저장 실패 안내
- 모바일 레이아웃, 키보드 조작, 공백 입력 검증

## 검증

- `node --check frontend/js/app.js`, `git diff --check` 통과
- Chrome에서 Enter로 추가, 완료 처리, 새로고침 후 데이터 유지, 진행 중·완료 필터, 개별 삭제, 공백 입력 안내 확인
- 데스크톱과 390px 모바일 화면 확인, 브라우저 콘솔 오류 없음
- 완료 일괄 삭제, 저장 공간 부족·손상 데이터 시나리오, 전체 키보드 탐색 및 다른 브라우저는 수동 검증하지 않음
