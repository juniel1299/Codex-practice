# 공통 개발 지침

- `frontend/`는 화면, `backend/`는 서버 코드를 담당합니다. 구체적인 앱 기능과 백엔드 기술은 요구사항이 정해지면 선택하세요.
- 새 코드는 공백 두 칸으로 들여쓰기하고, 파일과 폴더 이름은 기존 규칙을 따르되 새 이름은 kebab-case로 작성하세요.
- 요청과 관련된 부분만 수정하고, 불필요한 의존성 추가나 전체 서식 변경을 피하세요.
- 하위 폴더에는 해당 영역의 추가 규칙만 작성하세요. 계층별 적용 방식은 [공식 OpenAI 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md)를 참고하세요. 확인일: 2026-09-30.
- 변경에 맞는 검증과 `git diff --check`를 수행하고, 수행한 검사 및 확인하지 못한 동작을 작업 결과에 기록하세요.
